# Data Analysis Using Excel

A collection of Excel workbooks for practicing spreadsheet-based data analysis, table design, consolidation, and working with example business datasets.

## Files Included

- `CONSOLIDATION.xlsx` — workbook for practicing consolidation.
- `TEST_TABLE.xlsx` — table-based practice workbook.
- `concept_2.xlsx` and `concepts_1.xlsx` — Excel concept exercises.
- `data_analysis_Dr_table.xlsx` — workbook named for a data-analysis table exercise.
- `data_analysis_employee_table.xlsx` — employee-table practice data.
- `data_analysis_online_store_orders.xlsx` — online-store order data for analysis practice.
- `emi_file.xlsx` — workbook related to EMI calculations.

## Requirements

- Microsoft Excel or a compatible spreadsheet application such as LibreOffice Calc.

## How to Use

1. Download or clone the repository.
2. Open a workbook in Excel or a compatible application.
3. Inspect the sheet names, column headers, formulas, and sample records before editing.
4. Save a separate copy when experimenting so the original practice files remain unchanged.

## Learning Goals

The collection is suitable for practicing spreadsheet operations and analyzing structured data. Specific formulas, questions, and conclusions depend on the individual workbook.

## Notes

Workbook contents and formulas should be verified in the spreadsheet application before using the files for real business or financial decisions. No automated Python environment is required for the Excel files.
